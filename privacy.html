Privacy Policy

Last updated: October 28, 2026

About the Application

Family Command Center is a personal, non-commercial Raspberry Pi dashboard intended for private household use.

Google Calendar Data

With authorization, the application accesses Google Calendar events using read-only permissions to display calendar information on the household dashboard.

Data Storage and Sharing

Calendar data is processed locally for display on the household dashboard. The application does not sell calendar information or publish it on this website.

Access and Revocation

Google Calendar access can be revoked through the Google Account's third-party connections settings.

Contact

For privacy questions, contact the application developer using the support email listed on the Google OAuth consent screen.
